# Fact-check this

Podcasts and YouTube lectures are full of claims that feel like revelations.
Some of them are true, some are half-true, and some are wrong. You usually
can't tell which by how confident the speaker sounds. This site collects the
claims I run into, checks each one against real sources, and keeps a record
so the knowledge doesn't fade the way chat conversations do.

It has a second goal too: **learning to think about claims, not just
collecting answers.** Every check ends with a lesson from the
[Thinking toolkit](thinking/index.md). Before I see a verdict, I write down
how likely I thought the claim was, so the [Calibration](calibration.md) page
can show how often podcasts actually fool me.
