# Check the "therefore"

**The pattern:** a speaker strings facts together and lands on a
conclusion: "A, and B, *therefore* C." Listeners usually react to C:
they like it or they don't. But there are three separate questions:

1. **Are A and B true?**
2. **If they were true, would C follow?**
3. **Is C true anyway, for some other reason?**

A pleasant, generous conclusion makes it easy to wave through false
premises. An unpleasant one makes it easy to dismiss true ones.

**The habit:** write the argument out as steps and mark each one:

- each premise: true, false, or partly true;
- the link: does the conclusion really follow? Could the premises be true and the conclusion still false?
- the conclusion: what's the *best* case for it, whatever the speaker said?

Then you can say exactly where it breaks: "right conclusion, wrong
argument" is a perfectly normal result.

**Example:** "Moses, Jesus and Muhammad all spoke Aramaic, and in Aramaic
'God' sounds like 'Allah', therefore they all preached the same God."
Two of the three didn't speak Aramaic, a similar word doesn't make the same
God, and yet "the same God" is a position many Jews, Christians and Muslims
hold on quite different grounds. See [the check](../claims/moses-jesus-muhammad-spoke-aramaic.md).
