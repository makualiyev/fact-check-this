# Base rates

**The pattern:** "He predicted X, and X happened!" This feels like proof of
insight. But some predictions were likely anyway, and some are worded so
they can't fail.

**The habit:** for any prediction, ask:

1. **How likely was it at the time?** Check prediction markets, polls, or what most analysts expected. Calling the favourite tells you little.
2. **Was it specific?** A date, a clear outcome, ideally a probability. "Something big will happen soon" can't be wrong.
3. **What about the misses?** People remember the hits. A fair score counts every prediction made, including the wrong ones and the ones quietly dropped.
4. **Could it fail?** If no outcome would count as wrong, it isn't a prediction. Write the criteria down *before* the result, as on [this page](../predictions/us-loses-war-with-iran.md).
